English Database Dictionary

English Database Dictionary adalah website pembelajaran yang dibuat oleh Kelompok Database X RPL.

Website ini berisi kumpulan istilah Bahasa Inggris yang berhubungan dengan database dan teknologi informasi. Setiap istilah dilengkapi dengan arti Bahasa Indonesia, definisi Bahasa Inggris, penjelasan, contoh kalimat, terjemahan, serta fitur Text-to-Speech.

Project ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa backend dan tanpa API key sehingga dapat dijalankan secara langsung di browser, Acode, maupun GitHub Pages.
